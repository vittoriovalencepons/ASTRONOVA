# ASTRONOVA

ASTRONOVA es un pequeño juego arcade de navegador inspirado en los shooters espaciales clásicos.

## Cómo jugar

1. Abre `index.html` en tu navegador, o mejor aún sirve la carpeta con un servidor local.
2. Usa las flechas o `A/D` para moverte.
3. Pulsa `Espacio` para disparar.
4. Evita los enemigos y gana la mayor puntuación posible.

## Ejecutarlo localmente

La forma más sencilla es:

```bash
cd ASTRONOVA
python -m http.server 8000
```

Luego abre:

```text
http://localhost:8000
```

## Controles

- Mover: flechas izquierda/derecha o `A`/`D`
- Disparar: `Espacio`
- Reiniciar: botón "Restart"

## Objetivo

Sobrevive lo máximo posible y destruye a todos los enemigos que aparezcan.
